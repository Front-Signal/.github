# FrontSignal Organization Defaults (`.github`)

This repository holds the organization-wide issue intake forms and workflow defaults inherited across `@Front-Signal` repositories (`Front-Signal/fs-demo`, `Front-Signal/tracker`, and `Front-Signal/website`).

## Issue Intake Forms
1. **Customer Discovery & Suggestion for Review (`01_customer_discovery.yml`)** — Captures user interview takeaways and unvetted feature suggestions for product review before committing to engineering scope.
2. **Shared Capability / Feature Specification (`02_shared_capability.yml`)** — Enforces the Product & System Design tracking contract (System Layer `1–6`, Request Classification, Milestone `M1–M4`, Accountable Role, Intended Behavior, Remaining Tasks, and Demonstrated Behavior / Test Gate).
3. **Rubric, Config & Operations Task (`03_rubric_config_ops.yml`)** — Tracks non-code configuration specifications (`Banker`, `VC`, `Incubator`), rubric revisions, and operational tasks.
4. **Defect, Extraction & Isolation Bug Report (`04_bug_report.yml`)** — Captures reproducible defects with lineage metadata (`tenant`, `submission version`, `analysis run`, `configuration revision`, `rubric/model version`).
